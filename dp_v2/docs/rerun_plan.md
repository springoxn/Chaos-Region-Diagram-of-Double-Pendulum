### G2 为什么严重（**潜在**缺陷，被本次重跑触发）

字段名对不上：`make_gallery.m` 写 `amplitude_proxy_corr_with_lambda`，
`gen_report.py` / `verify_manual.py` 读 `old_metric_corr_with_lambda`。

**精确的时间线**（据文件实证，非推测）：

| 时间 | 事件 | `summary.mat` 里的键 |
|---|---|---|
| 2026-09-20 23:23 | 当时的 `make_gallery.m` 产出 `summary.mat` | `old_metric_*` ✅ |
| 之后某次编辑 | `make_gallery.m` 的字段名被改成 `amplitude_proxy_*`，**生成器未同步** | — |
| 本次重跑前 | 生成器读 `old_metric_*`，而新代码只写 `amplitude_proxy_*` | 将缺失 ❌ |

所以这是一个**潜在**缺陷：旧 `summary.mat` 里 `old_metric_*` 存在，生成器一直正常工作
（`report.html` 里的 `0.912` / `0.1953` 是**真值**，不是回落值——
我在本节初稿里写成"文档一直在引用硬编码数字"，**那句话是错的，已更正**）。

真正的问题是：**A 节要求的重跑一定会触发它**。`read_summary()` 在构造字典的**第一个键**
就抛 `AttributeError`，被裸 `except` 吞掉后返回整份硬编码字典，于是

```

basin_alpha → 0.2026  （真值 0.1953）
basin_D     → 1.7974  （真值 1.8047）
```

**全部**数值静默变成 2026-09-20 之前的陈旧字面量，而构建仍然"成功"。
`old_corr` 本身在正文里根本没被渲染（读了但没用），所以这个缺陷不会有任何可见症状。

修法：
1. 字段名两侧统一——`make_gallery.m` 现在**两个名字都写**（外加 `old_metric_note`）；
2. 生成器**遇到缺键直接 `SystemExit`**，不再回落（裸 `except` 是掩盖手段本身）；
3. `verify_docs.m` 从 MATLAB 侧断言 `gen_report.py` 读取的每个 `s.<field>`

**重跑复现性**：新的 `old_metric` = `-0.019908848870629627`，与 2026-09-20 的

### Mathieu 验证结果（`analysis/sp_mathieu_bands.m` + `tests/test_mathieu.m`）

论证链：`y=Y=0` 时变分方程解耦（论文 Eq. 23）→ 横向模 `δy'' = -a(1-b cos x)δy`
（Eq. 25）→ 循环区代换 `u=Ωt` 得 Mathieu 方程（Eq. 26）→ 失稳带在 `ξ = k/2`
（Eq. 27），即 `Ω = 4/k`（Eq. 28）。

实测（本项目自己的辛步进器，`δy` 模态播种）：

| 带 | X 峰值 | Ω_eff | ξ | Ω_eff vs 4/k 相对误差 |
|---|---|---|---|---|
| k=2 | 2.52 | 1.9941 | 1.0030 | **0.30 %** |
| k=1 | 4.33 | 4.0776 | 0.4905 | **1.94 %** |

`max |ξ − k/2| = 0.0095`。**论文的解析预测成立。**

**一个必须随数字一起走的细节**：论文用**初速度 X** 标注共振（"stripes begin at
X ~ 4"），但 Ω 是**循环频率**，只在快循环极限下才等于 X。实测 `X/Ω_eff`
从 X=2.05 处的 1.86 降到 X=6 处的 1.03。用 Ω_eff 才使预测变锐利；
直接读 X 会留下 5–15 % 的系统偏差，**容易被误判成理论失效**。

另一条同样要记住的：`ξ = k/2` 是 **b → 0** 的陈述。b = 1 时带**整体上移**且
位移随 k 增大（k=1: +0.035；k=4: +0.215），这是 Mathieu 特征值
`A_n = n² + O(Q²)` 的已知位移。`tests/test_mathieu.m` 分两段断言：
小 b 处带必须包含 `k/2`，b = 1 处位移必须为正。

**踩过的坑（写下来以免重犯）**：`[x; y; X; Y]` 是**坐标在前**。
横向位移 `δy` 是**分量 2**，分量 3 是 `X`。播种分量 3 量到的是规则的
`δx` 模态、完全没有带。本项目两次踩这个坑（`sp_run` 的 `nGali=1`
播种的也是 `δx`）。对照实验 [4] 现在固定断言 `δx` 全程规则（max 0.0003）
而 `δy` 共振（max 0.462）。

### Hénon–Heiles 验证结果（`maps/sp_henon_heiles_map.m` + `tests/test_henon_heiles.m`）

`sp_sys('henonheiles')` 实现了论文 Eq. (20)
`H = (X²+Y²+x²+y²)/2 + x²y − y³/3`，含解析 `force`/`dforce`/`d2force`
（三阶导是 `sp_ofli2` 的输入）。初始条件由 `sp_henon_heiles_ic.m` 在**固定能量面**上
反解一个动量，能量精确到 **3e−17**。

**Fig. 12（积分时间）** —— 论文说 `tf = 50` 会给出"完全错误"的图。
以 `tf = 2000` 为参考，按秩相关量化（E=1/8，N=41）：

| tf | Pearson | **Spearman** | 中位相对差 |
|---|---|---|---|
| 50 | 0.513 | **0.563** | 0.948 |
| 100 | 0.707 | **0.785** | 0.917 |
| 200 | 0.815 | **0.872** | 0.875 |
| 500 | 0.891 | **0.937** | 0.725 |
| 1000 | 0.945 | **0.972** | 0.428 |

**单调收敛，论文的警告可复现。** `test_henon_heiles.m` [4] 断言单调性、
`tf=50` 必须 < 0.7、`tf=1000` 必须 > 0.9。

**Fig. 11（初始变分向量）** —— 四种 `η₀` 的 FLI 地图（E=1/8，N=25，T=200）：

| η₀ | 均值 | std |
|---|---|---|
| `∇H/‖∇H‖`（论文推荐的 "good"） | 7.719 | 4.407 |
| `(1,1,1,1)/2`（fixed） | 7.444 | 4.765 |
| `(−f₄,−f₃,f₂,f₁)/‖f‖` | 7.720 | 4.933 |
| `f/‖f‖`（沿流切向） | **0.288** | 0.307 |

沿流切向被**压制到 4%**，这正是论文指出的机制：初始向量落在流切向上时，
一阶指标只能看到代数增长，于是读出"异常规则"的伪结构。

#### 一个必须记下的**证伪**结果：`Y → −Y` 不是对称性

论文 §4.3 说 `tf=50` 那幅"not symmetric in spite of the symmetry of the problem"。
我据此假设对称性是 `Y → −Y` 并去测，**测不出来** —— 而且不对称度随 `tf` **增长**，
不可能是噪声。

原因是势含 `−y³/3`，所以 `y → −y` **根本不是**对称性。
逐点验了三个候选对称（`probe_hh3`）：

| 变换 | 是否成立 |
|---|---|
| `X → −X` | **成立，机器精度**（OFLI2 与取哪个根无关） |
| `(x,y,X,Y) → (−x,−y,X,−Y)` | 不成立 |
| `Y → −Y` | 不成立 |

所以论文那句话依赖的对称性我**没有定位到**；改为不依赖对称性论证的
**秩相关收敛**（上表）来验证 Fig. 12 的实质主张。`test_henon_heiles.m` 的注释里
记了这次证伪，以免下次再假设一遍。

#### 另一个易错点：FLI 的 `renorm`

我一度以为"FLI 是 `ln‖n‖` 的上确界，所以不能归一化"，于是传 `renorm=false`
—— 结果向量溢出，地图值变成 **4.5e4**。
正确做法是**归一化**：累计 `Σ ln g_k = ln‖n(t)‖ − ln‖n(0)‖`，
所以对上确界而言两者**完全等价**，而归一化不会溢出。
这与 `sp_ofli2` 不归一化并不矛盾：OFLI2 积的是投影组合、窗口短得多。
