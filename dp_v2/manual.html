核心 · dp_lyap

双摆的最大 Lyapunov 指数，可选完整谱。数值核心。

[lam, info] = dp_lyap(y0, T, dt, p) [lam, info] = dp_lyap(y0, T, dt, p, opts)
参数类型说明
y04×1初始状态 [th1; om1; th2; om2]
T标量积分时长（秒）
dt标量定步长 RK4 步长。长时间积分建议 ≤0.01
pstructm1, m2, L1, L2, g
optsstruct见下，可省略
opts 字段默认说明
transient0.3*T平均前丢弃的时长（秒）
reortho10重正交间隔（步）
methodtangenttangent（变分法）或 shadow（双轨迹法）
d01e-10双轨迹法的初始分离
nExponents11–4；>1 返回完整谱
progressfalse打印进度
返回说明
lamnExponents×1 降序；lam(1) 最大
infonSteps, nSamples, tTransient, tTotal, reortho, energyDrift, method
p = struct('m1',1,'m2',1,'L1',1,'L2',1,'g',9.81);

lam = dp_lyap([2.5;0;2.5;0], 400, 0.005, p, struct('transient',120));
%  -> +1.3191

lam4 = dp_lyap([2.5;0;2.5;0], 400, 0.005, p, ...
               struct('transient',120,'nExponents',4));
%  -> [1.3191, 0.0019, -0.0038, -1.3165]    哈密顿系统，和 = 0

ls = dp_lyap([2.5;0;2.5;0], 400, 0.005, p, ...
             struct('transient',120,'method','shadow'));
%  -> +1.3195    与变分法相差 3.4e-04，独立校验
两种方法

tangent 用机器生成的解析 Jacobian 积分变分方程并定期 QR 重正交（Benettin 算法）。收敛快，能给出完整谱。

shadow 积分两条邻近轨道、定期重整分离向量，不使用 Jacobian。收敛较慢，对重正交间隔有 O(h) 偏差，只用做独立校验。

完整谱需要真正的 QR

最大指数只需一个切向量，重正交就是归一化。但 nExponents>1 时切基会退化，必须做真正的 QR 分解。dp_lyap 在两种情形下都用 QR，因为 n 很小、代价可忽略。

核心 · fp_lyap

受迫阻尼摆的指数与旋转数。

theta'' + gamma*theta' + sin(theta) = F*cos(Omega*t) [lam, info] = fp_lyap(th0, om0) [lam, info] = fp_lyap(th0, om0, opts)
opts 字段默认说明
F1.5驱动幅度
gamma0.2阻尼
Omega2/3驱动频率
dt0.01RK4 步长
periods300驱动周期数，不是秒
transient0.3丢弃比例（0–1）
reortho10重正交间隔（步）
methodtangenttangent 或 shadow
d01e-10双轨迹法初始分离

返回 info 含 winding（<omega>/Omega）、meanOmega、nSteps、tTotal、method。

% F=1.5, gamma=0.2：两个吸引子都混沌，靠 winding 区分
[v, info] = fp_lyap(1.0, 0.0, struct('F',1.5,'gamma',0.2,'Omega',2/3, ...
                                     'dt',0.01,'periods',250));
%  v = +0.0480,  info.winding = +2.0009

[v2, i2] = fp_lyap(2.5, 0.0, struct('F',1.5,'gamma',0.2,'Omega',2/3, ...
                                    'dt',0.01,'periods',250));
%  v2 = +0.0377,  i2.winding = -1.9999    反向旋转
积分长度以驱动周期计，不是秒

固定秒数在不同 Omega 下意味着不同的驱动周期数，频率扫描会因此无法自比。periods 保证跨 Omega 可比；info.tTotal 同时给出物理秒数。

核心 · 辅助函数

dp_check_params

p = dp_check_params(p)

补全默认值（全 1，g=9.81）并校验物理合理性：质量、长度、g 必须为正。所有核心函数都经由它，因此缺字段会在入口处明确报错，而不是在扫描深处静默产生错误积分。

dp_traj / fp_traj

yEnd = dp_traj(y0, T, dt, p) thetaEnd = fp_traj(th0, om0, T, dt, opts) [thetaEnd, omEnd] = fp_traj(...) [theta, om, t] = fp_traj(...) % 三个输出时返回完整轨迹

fp_traj 的 opts 字段为 F, gamma, Omega。

dp_rk4_step

y_new = dp_rk4_step(y, dt, p) [y_new, Phin] = dp_rk4_step(y, dt, p, Phi)

单步 RK4。给出 Phi 时同时推进切空间矩阵 Phi' = J(y)·Phi，共用同一组 RK4 级——切向量与轨迹必须用一致的格式积分，否则 Lyapunov 指数会继承格式不匹配带来的系统误差。

dp_jacobian / dp_jacobian_apply

J = dp_jacobian(th1,om1,th2,om2, m1,m2,L1,L2,g) % 4x4，单点 A = dp_jacobian_apply(th1,om1,th2,om2, v1,v2,v3,v4, m1,m2,L1,L2,g) % 4xN，批量

两者都是机器生成的（gen/gen_jacobian*.py），勿手改。dp_jacobian 供单点使用；dp_jacobian_apply 直接展开 J·v，共享分母只算一次，是地图扫描快路径的关键。

为什么必须是解析 Jacobian

用有限差分近似 Jacobian 会把 O(h) 误差直接注入切流，偏置的正是要测量的量。生成脚本自带校验：与中心差分对比，两点误差 8.9e−10 / 1.9e−09；test_speed 另测 apply 与 J*q 的一致性（5.3e−15）。

地图 · 精度挡位 dp_apply_tier

o = dp_apply_tier(o) % o.tier 展开为 N / T / dt / periods

收敛的 Lyapunov 指数需要 T >> 1/lambda，这是全部成本。与其让每次使用都付出发表级代价，三挡已标定的设置被提供。显式给出的值优先于挡位，所以可以 ('tier','preview','N',200) 混用。

挡位双摆 (N, T, dt)受迫摆 (N, periods)误分类率误差位置
preview48, 30, 0.0248, 604.1 %边界 0.33 格内
standard120, 120, 0.01120, 2502.3 %边界 0.22 格内
accurate240, 400, 0.005240, 800参考—

"误分类率"是与 accurate 相比，把点判到规则/混沌另一侧的比例。误差全部集中在边界一格以内。标定脚本：tests/test_tiers.m；数据：docs/perf_tiers.md。

dp_apply_tier(struct('tier','preview','N',0,'T',0,'dt',0))
%  -> N=48, T=30, dt=0.02

% 挡位 + 覆盖
M = dp_map_lyapunov('tier','preview','N',200);   % N=200，其余按 preview
不要把 preview 的结果当作数值结论

preview 用于判断"混沌区在哪里"，不是用来引用 λ 的具体数值。需要数值时用 accurate。

分析 · basin_dimension

盆地边界维数，用不确定指数法。

R = basin_dimension(basin) R = basin_dimension(basin, 'nBalls',5e5, 'plot',true)

输入是整数/实数标签矩阵，例如 M.basin。

选项默认说明
nBalls4e5随机采样点数
nEps26尺度个数
maxEps40最大球半径（像素）
fLo, fHi0.02, 0.9参与拟合的 f 范围
seed0随机种子（可复现）
plotfalse画标签图与标度律
verbosetrue打印 alpha、D、R²
返回字段说明
alpha不确定指数
D2 − alpha
R2幂律拟合优度
eps, f标度曲线原始数据
fitMask哪些点进入拟合
saturated标记 alpha=0 被钳制的情形

原理

随机取点，测半径 ε 的邻域内包含多于一类盆地的概率 f(ε)，则 f ~ ε^alpha，且

alpha = d − D 即 D = d − alpha （d = 2）
符号方向容易写反

正确写法是 alpha = d − D，即 D = d − alpha。D 在减号右边。因为分形边界有 0 ≤ alpha ≤ 1，所以 D 落在 d−1 与 d 之间。把 alpha 当成较大的那个量是错的。

alpha边界性质D说明
1平滑d − 1最可预测
(0,1)分形d − alpha本项目 F=1.5 属此类
0riddleddD 不是有效描述量
alpha ≈ 0 时不要引用 D

alpha=0 意味着边界填满相空间，D=d 只是说"占满了"。函数在这种情况下会明确拒绝给出 D 并说明原因，而不是返回一个看起来正常的数。

M = fp_map('N',200, 'F',1.5, 'gamma',0.2);
R = basin_dimension(M.basin, 'plot',true);
fprintf('alpha = %.4f  D = %.4f  R2 = %.4f  (N=%d)\n', ...
        R.alpha, R.D, R.R2, R.N);
fprintf('boundary pixels: %.1f%%\n', 100*R.boundaryFrac);
%%  ->  alpha = 0.1953   D = 1.8047   R2 = 0.9645   (N=200)
网格太细的问题

N 过小时标度律无法拟合，函数会报错并打印完整的 f(eps) 曲线，而不是返回不可信的数。N=200 可以稳定拟合。

分析 · fp_melnikov_threshold

Fc = fp_melnikov_threshold(gamma, Omega) [Fc, sechFactor] = fp_melnikov_threshold(gamma, Omega)
M(t0) = −8*gamma + 2*pi*F*sech(Omega*pi/2)*cos(Omega*t0) 简零存在（⇒ 横截异宿纠缠 ⇒ Smale 马蹄）当且仅当 F > F_c = (4*gamma/pi)*cosh(Omega*pi/2)
fp_melnikov_threshold(0.2, 2/3)     % -> 0.40751
fp_melnikov_threshold(0.5, 2/3)     % -> 1.01877
% cosh(pi/3) = 1.600287，故 F_c = 2.037549 * gamma

函数内部自查 (4/pi)cosh = 4/(pi*sech) 恒等式。

Melnikov 的适用边界

它是一阶微扰结果，只在小 gamma、小 F 下定量可靠。它保证的是马蹄（几何/暂态意义），不保证混沌吸引子存在。

用法：用它定位转变点，再用 fp_lyap 验证。数值上 F=1.00（F/F_c=0.982）时 lambda_max=−0.0070，几乎精确压在零上。

指标族 · sp_*

受迫摆是 2 维耗散流，GALI/SALI 在此退化（实测 27% 假阳性）；双摆是 4 维，GALI 才是主场。因此 指标选择依赖系统维度：双摆用 GALI/MEGNO，受迫摆用 MEGNO/OFLI2/IACF。

sp_sys

sys = sp_sys('pendulum', 'F',1.5, 'gamma',0.2, 'Omega',2/3) sys = sp_sys('coupled', 'a',4, 'b',1)

可分哈密顿系统 H = |p|²/2 + V(q)（单位质量），携带force / dforce（解析 Hessian）/ d2force（三阶导，供 OFLI2）/ energy。导数全部解析：差分会在切空间里注入 O(eps) 误差，而切空间正是所有变分指标的来源。选项名写错会直接报错，不静默取默认值。

sp_step

[y, V, g, t] = sp_step(y, V, t, h, sys, order)

显式辛单步（Yoshida 2/4/6），同时按同一合成映射推进切空间。order = 2 即 Verlet。g 是每步被除掉的范数，是 Lyapunov / MEGNO / FLI 的原始材料。受迫摆 gamma>0 时阻尼作为可精确求解的收缩算子 Strang 夹在两端，保守部分保持严格辛结构。

sp_run

R = sp_run(sys, Y0, opts) % Y0 是 ndof x N，一整行初值同步推进
选项默认说明
order4Yoshida 合成阶：2 | 4 | 6
T, dt100, 0.01积分时间与步长
transient0.3平均前丢弃的比例
nGali2跟踪的偏差向量数 1..ndof
sample[]采样间隔（步）；[] 由 nSamp 推
spectralfalse是否逐点计算 IACF / SN（见下）

返回 lambda、mega（MEGNO）、fli、gali、sali、galiSeries、iacf、specnum。

MEGNO 的 T 门槛

实测 T=100 → 1.75、T=3200 → 1.9993。T < 1000 的 MEGNO 定量结论不可信，地图上尤其容易踩（periodsInd 默认 200 周期偏短）。

谱指标为何要显式打开

iacf/specnum 需要逐点的时间序列。它们与 MEGNO/GALI 出自同一次积分（无第二次轨迹遍历），但每点要跑一次自相关/FFT，所以默认关闭。

sp_run 曾把这两个字段硬编码为 [] —— 字段存在、永远为空、且不报错。现已实现并加回归测试。

sp_run_dp

R = sp_run_dp(y0, T, dt, p, opts) % y0 是 4xN，行序 [th1; om1; th2; om2]

双摆版驱动，走隐式辛步进器 —— 双摆哈密顿量不可分（M(q) 依赖坐标），不存在显式辛格式，必须用隐式中点/2 阶 Gauss。返回 galiAll(k,:)，同时给出 GALI₂/₃/₄。nGali = 1 时 R.sali 为 []：SALI 定义在恰好两个向量上。

sp_gali / sp_sali / sp_ofli2

g = sp_gali(V) % V 是 ndof x k x N，返回 GALI_k = ||v₁^…^v_k|| s = sp_sali(V) % 恰好两个向量；GALI₂ = SALI·sqrt(4−SALI²)/2 O = sp_ofli2(sys, Y0, opts) % 二阶变分，需 sys.d2force

GALI 用薄 QR 的 |det R| 计算楔积范数，数值稳定。偏差向量只归一化、不正交化：Gram-Schmidt 会强制正交，而正交性正是 GALI 要测的东西。

sp_iacf / sp_specnum

[W, info] = sp_iacf(q, 'B',40, 'maxLagFrac',0.75) [SN, info] = sp_specnum(q, 'cutoff',0.1)

论文 Eq.11–17 的积分自相关 W 与谱峰计数 SN。二者都是谱指标：只看一条轨的时间序列，完全不碰变分方程，因此是论文推荐的「与变分指标对质」的独立交叉检验。

W 默认用精确的全滞后求和

论文的 log-lag cascade（Eq.15–17）是一个近似，实测在正弦上差 0.13%，但在宽带序列上差 31–38% —— 而宽带正是混沌轨道的样子。

旧版把触发阈值设成 2e8，使该分支实际不可达（死代码）。现在精确和是默认，cascade 只能显式要求（'fullLimit',0）。

sp_map_dp / sp_compare_dp / sp_compare_forced

M = sp_map_dp('N',40, 'T',40) % 双摆 GALI/MEGNO 地图 R = sp_compare_dp('N',12, 'T',40) % 双摆：各指标 vs 真 λ R = sp_compare_forced('cases',{{1.1 0.5}}) % 受迫摆：同上

对照函数用 Spearman 秩相关作头条：地图需要的是点的排序正确，不是线性关系。真值 lambda 来自既有内核 fp_lyap_row / sp_run_dp，刻意用不属新代码的部分来评分。

地图必须是网格

sp_map_dp 与 sp_compare_dp 曾把初值写成 [th1v;0;th2v;0]，那只走 (θ₁,θ₂) 平面的对角线 —— 矩阵秩为 1，每行逐位相等。它不报错，图看着也正常。

现在有 rank(lambda) >= 2 的断言，并与既有 RK4 地图在同一 slice 上做相关性检查以钉住取向。

sp_mathieu_bands

R = sp_mathieu_bands('mode','both', 'b',1, 'fig',true)

验证论文 Eq.26–28 的解析预测：横向模 δy 满足 Mathieu 方程，失稳带在 ξ = k/2，即 Ω = 4/k。实测用本项目自己的辛步进器给出 Ω_eff = 4/k 误差 0.30% / 1.94%（k=2 / k=1）。

状态布局是 [x; y; X; Y] —— 坐标在前

横向位移 δy 是分量 2，分量 3 是 X。播种分量 3 量到的是规则的 δx 模态、完全没有带。

另外 ξ = k/2 是 b→0 的陈述；b=1 时带整体上移且位移随 k 增大。论文用初速度 X 标注共振，但 Ω 是循环频率，只在快循环极限下相等 —— 实测 X/Ω_eff 从 1.86（X=2.05）降到 1.03（X=6）。

工程 · 实现注意事项

这些是开发中实际踩到、并且会影响结果正确性或可读性的点。

事项说明
角度必须折回受迫摆旋转轨道的 θ 会累积到 ~1e4 rad，双精度在该量级的间距足以淹没双轨迹法的 1e-10 扰动。折回 [−pi,pi) 是精确操作。
切向量必须在瞬态期就归一化否则切向量在进入平均窗口前已溢出，得到无意义的指数。
有限时间 λ 的符号不可用于判据规则轨道在 T≥400 时 λ 为正（约 +0.001–0.006）。按量级读图。
绘图失败不得毁掉测量basin_dimension 把绘图包在独立的 try 中：调用者先要的是测量，其次才是图。
chained indexing 在 R2021a 不可用d(:).max() 会报"不支持的操作数"而非语法错误，先赋值给变量再索引。
clim 在 R2021a 不存在需回退到 caxis。
cell 字面量中不能夹注释在 ... 续行与下一个元素之间插入注释会破坏解析，报"维度不一致"。
parfor 变量分类parfor 体内构造的结构体要能被正确切片；行级循环是最自然的粒度。
一条通用原则

每个"快路径"都必须有一个测试断言它与慢路径给出相同的结果。改变答案的优化不是优化。本项目的做法是：test_speed / test_speed_fp 逐点比对两条路径，并要求加速比本身也作为断言。
